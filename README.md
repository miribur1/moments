# Moments 😌😣

A lightweight, privacy-first Hebrew mindfulness & daily reflection Progressive Web App (PWA). Designed to quickly capture positive and challenging moments throughout the day, track physical sensations, thoughts, and emotions, and reflect in the present moment.

## ✨ Features
* **100% Private & Local:** All entries are stored exclusively in your device's browser (`localStorage`). No servers, no accounts, and zero data collection.
* **Fast Daily Logging:** Auto-fills the current date, Hebrew day of the week, and time, with quick-tap chips for common physical sensations and emotions.
* **Adaptive Responsive Table:** Shows a clean 2-column overview in portrait mode (`יום ושעה` | `אירוע`) and automatically expands to all 6 reflection columns when rotating to landscape or viewing on desktop.
* **Filter, Search & Sort:** Filter by positive (`😌`) or challenging (`😣`) moments, filter by date range, sort newest/oldest, and search across all fields.
* **Data Ownership:** One-tap export to Excel-compatible CSV (UTF-8 with BOM) and full JSON backup/restore.

## 📲 How to Install on Your Phone
1. Open the live app link in **Chrome** (Android) or **Safari** (iPhone).
2. **Android:** Tap the top-right menu (`⋮`) → **"Add to Home screen"** / **"Install app"**.
3. **iPhone:** Tap the bottom **Share** icon (`⬆️`) → **"Add to Home Screen"**.

## 🗂️ Project Structure
* `index.html` — Complete single-file application (HTML, CSS, and Vanilla JS).
* `manifest.json` — PWA configuration for standalone home-screen installation.
* `icon.png` — App icon.
